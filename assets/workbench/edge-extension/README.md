# 本机浏览器收藏连接 · 1.0.3

本目录供支持所需Manifest V3接口的Chromium浏览器使用。Chrome/Edge走标准路线；搜狗、360需具体版本和高速/极速内核验收，不能保证全部可用。

在用户已登录抖音的同一浏览器/profile中加载本目录。点击扩展图标的“检查浏览器兼容性”，再按工作台“我的→连接现有浏览器”做一次性配对。接口检查不读取账号或Cookie；接口缺失会阻止同步。若扩展无法加载，转宿主可见浏览器读取或用户提供链接，此时不能承诺后台自动同步。

完成少量收藏真实读取后，再开启自动化。默认收藏24小时；扩展每分钟检查本机任务不等于每分钟采集抖音。当前分享版尚未在Chrome、搜狗、360实机验证登录/分页/后台同步。

权限只含scripting/storage/alarms，网站仅www.douyin.com和127.0.0.1，代码固定8765。不申请cookies/history/debugger权限、不迁移登录、不另建profile。遇登录/验证暂停，浏览器关闭或电脑休眠不能同步。

一套工作台一次配对一个采集浏览器，新配对替换旧连接；其他浏览器仍可查看工作台。后台可能临时打开同一profile的收藏标签，不导航或关闭原标签；回填按实际页面情况保留位置。未明确显示的时间和指标保持未知。内部文件名和/edge路由保留历史命名以兼容，不表示强制Edge。
