# 发布标签与发现关键词

两者不同。发现关键词是交给TikHub搜索素材的词组，会计费；发布标签用于作品发布时表达主题或参与活动，不会因保存自动发起搜索、报名或投稿。只有用户明确希望把某标签用于素材发现时，才另加到search_keywords。

## Agent如何整理

先从访谈提炼行业/受众/需求/内容形式，再找真实作品及平台话题页验证用语；无浏览器能力时可用公开网页或用户提供资料，缺证据标待核实。AI类可参考用户指定的https://betteropc.com/self-media/traffic-tags，其他行业查对应平台与行业来源，不套用AI清单。

BetterOPC为第三方整理页面，站内热度不是抖音热度；页面更新时间不是活动重新生效时间。常用话题与有截止日的活动分开看。参与条件、报名、发布入口、回填、有效期需以活动方最新规则为准；禁止把已失效/未来活动当成当前有效活动。不能承诺带标签就涨流量。

本次2026-11-13页面可见的AI常用候选包括“我在抖音聊科技”“ai新星计划”“我在抖音学ai”等，作为示例线索，不能作为永久默认。该页对同一话题可能分别列常用合集和已结束活动，不能混淆话题还能使用与活动奖励仍然有效。

## 保存格式

profile.json可选traffic_tags，最多30项。缺省不覆盖已有标签，显式[]才清空。示例仅说明结构，不替用户确认活动：

```json
{"tag":"我在抖音聊科技","platform":"抖音","purpose":"主题","status":"待核实","source_url":"https://betteropc.com/self-media/traffic-tags","checked_at":"2026-11-13T09:00:00+08:00","valid_until":""}
```

tag可带#；platform为抖音/小红书/其他，purpose为主题/活动，status为待核实/已核实/已失效；checked_at为实际检查时间含时区，不照抄示例；valid_until为空表示未确认截止日期，不表示永不过期。只保存无账号票据/凭据的HTTPS来源链接，不保存含登录票据的分享参数。新标签仅用第三方汇总时通常标待核实，读取官方规则后才可标已核实。小红书标签参考不代表本包已接通小红书采集。

工作台「内容方向与关键词→发布话题标签」显示已保存标签与来源；Agent通过profile辅助命令更新。当前未内置标签网站自动同步或跨行业官方标签库。
