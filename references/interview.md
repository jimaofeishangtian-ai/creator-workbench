# 三组首次访谈

先复用已知内容，允许自由描述，一次不问超过三组：

1. 你做哪个行业/细分领域，内容给谁看，希望解决什么问题或达到什么目标？
2. 最想参考哪2—3类视频（教程、成品案例、测评、观点等），不想看到什么？有参考作品/作者最好，没有也能开始。
3. 更需要近期热点、低粉爆款还是两者？有没有要跟踪的博主？愿意用付费数据/模型服务吗，月上限是多少？未决定费用时可先整理收藏，自动化保持关闭。

Agent先形成：行业和细分赛道、受众、内容形式、目标、排除项、5—10个本地匹配词、3—8个初始搜索词，以及有来源的发布标签候选。关键词数量是起步建议而非限制。例：健身→上班族居家无器械练腿，不能只搜“生活/教程”；餐饮→快手家常菜；装修→小户型收纳改造。AI只是其中一种行业。

profile.json字段如下；真实回答替换示例：

```json
{
  "domain":"居家健身",
  "audience":"时间少的上班族新手",
  "goal":"找到可复现的动作讲解与选题",
  "formats":["动作讲解","跟练"],
  "include_keywords":["居家训练","练腿","无器械"],
  "search_keywords":["居家练腿","无器械腿部训练","上班族健身"],
  "exclude_keywords":["代餐"],
  "prefer_low_followers":true,
  "categories":["动作方法","训练安排","纠错","训练效果","其他"],
  "examples":["实拍一个动作并讲常见错误"],
  "traffic_tags":[]
}
```

`prefer_low_followers`保留作访谈偏好；当前低粉榜始终执行低粉门槛，看不限粉丝内容用热点推荐/对标新作，不用此字段绕过榜单条件。没有核实标签时traffic_tags留空或把已有候选标待核实；格式见tags-and-keywords。

预览包括词的用途和来源，不把“发布话题”混进付费搜索。无对标/关注也可以仅用搜索。初期先检视5—10条实际样本的保留/排除原因再改词，不为了验证连续跑多轮付费查询。
