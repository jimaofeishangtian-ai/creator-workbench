# 选择用户已经登录的浏览器

先问抖音登录在哪个浏览器及哪个profile；保留那份登录，不以默认浏览器或已安装品牌替代用户选择。不复制Cookie、不迁移登录、不另建profile。

| 浏览器 | 当前接入方式 | 验收边界 |
|---|---|---|
| Chrome / Edge | Manifest V3标准扩展路线，使用包内同一扩展目录 | 标准API具备技术兼容基础；仍需在该用户机器实读一次 |
| 360安全 / 360极速 | 核对版本、Chromium/极速模式和MV3，再检查接口 | 不能因“支持Chrome插件”就保证当前扩展可用 |
| 搜狗高速 | 核对版本、高速内核、MV3和必要接口 | 不是所有版本通用，加载失败转宿主可见页面读取 |
| 不支持本扩展 | 宿主Agent有本机浏览器工具时读取可见页面 | 仅手动/Agent辅助读取，后台自动收藏同步仍待适配 |

插件弹窗提供“检查浏览器兼容性”，检查MV3、scripting、tabs、storage、alarms及使用的JS能力。检查仅证明接口存在，不证明登录、页面分页或定时任务成功。扩展根本不能加载时，检查也不能运行；如实报告，不反复重装或让用户重登账号。

官方依据（2026-11-08核对）：[Chrome加载MV3扩展](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)、[Chrome scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[搜狗扩展](https://ie.sogou.com/help/help-3-5.html)、[搜狗内核切换](https://ie.sogou.com/help/help-4-7.html)、[360扩展示例](https://open.se.360.cn/open/extension_dev/getstarted.html)。搜狗的扩展说明和360的旧MV2示例均不能证明具体版本支持本包MV3方案。

## 收藏连接

目录仍叫assets/workbench/edge-extension/，是历史命名；界面已称本机浏览器连接。内部/edge路由及AIWorkbenchEdge消息名保留兼容，不能只改一端。

1. 在用户已登录抖音的**同一浏览器/profile**加载解压扩展，由用户按宿主和浏览器规则确认必要权限。
2. 点击扩展图标做兼容接口检查；在同一浏览器打开工作台“我的→连接现有浏览器”，生成一次性配对码并连接。若启动器打开默认浏览器而非采集浏览器，复制工作台地址到正确浏览器，不能因此配错账户。
3. 保持一个抖音标签，手动同步少量收藏，核对实际入库和任务状态后再设每日同步。
4. **一套工作台一次保留一个采集浏览器配对**；新配对替换旧连接，操作前说明。其他浏览器可查看工作台，采集仍来自指定浏览器。

作品数据只发本机127.0.0.1:8765；首批最多300条，历史按用户要求继续。出现登录/验证暂停交用户；电脑、服务和采集浏览器需运行。后台分页停滞提示前台同步，未显示的收藏时间、日期、指标保持未知。

## 关注候选读取

扩展当前负责收藏；关注由宿主Agent在**同一实际登录浏览器**首次读取。优先使用宿主允许的现有标签控制；有原生电脑控制时可操作该浏览器。缺工具就请用户提供主页链接/核对截图，不能凭空获得本机能力。

根据实际页面打开本人关注列表，记录可见昵称、真实主页href和领域依据；不猜链接/接口、不导出Cookie。每批最多500位或10分钟，先到先停标partial；只有看到结束才标complete。验证或登录异常不能报成空关注。

用save-following保存候选，再按用户领域建议5—15位对标，用户选择或授权明确规则后才select-following。未选候选不监控。不支持扩展的浏览器即使能手动读取，也不因此具备后台自动收藏；配置好的TikHub仍可执行已选对标和搜索的日任务。

2026-11-09：连接弹窗先选择采集浏览器，无默认Edge；再展示对应安装说明并生成配对码。选择只决定指引，实际来源取决于在何浏览器/profile完成扩展配对，不自动切换、迁移或重登。
